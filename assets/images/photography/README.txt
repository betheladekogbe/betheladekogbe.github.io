PHOTOGRAPHY GALLERY

Add JPG, JPEG, PNG, WEBP, or AVIF photos to this folder.

Your photography page automatically discovers these images through Jekyll,
displays them in an editorial-style responsive grid, and shuffles their order
on each page load. The page also has a Shuffle button and image lightbox.

Suggested workflow: export images from Google Photos, resize to 1600–2000px
on the longest side, then add the selected files here. Use descriptive filenames.
